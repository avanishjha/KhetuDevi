Predefined skill demos

Every card opens a real, working demo that ships with the installed skill — not a mockup and not something I wrote. Click through, and tell me which ones to build the Trust site from. You can mix: one for the page structure, one for the surface treatment, and any number of components.

Requires both dev servers running. If a link 404s, the demos server on port 4322 has stopped.
